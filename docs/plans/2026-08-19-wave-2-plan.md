Phased gated plan for the next boardkit wave, built for Mike's review

## Decisions (Mike, in-session 2026-08-19)

1. **R-wave close.** Mike's design-read of the review packets stands as
   the U(code-review) substance for the ten in-review cards. Where a
   card's read raises nothing, Gate A and Gate U tick on the 2026-08-16
   ruling record and the card goes done. No sixth review round.
2. **Audit trail shape: sidecar plus receipts.** An ArtifactStore seam
   beside CardStore, with a per-board posture key in `boardkit.toml`:
   `ephemeral` (today's gitignored dirs), `in-repo` (tracked archive),
   or `sidecar` (a private git repo or directory the CLI pushes packets
   to). The tracked repo carries only a compact review receipt per
   gate: verdict, numbered findings ledger, author and reviewer models,
   and content digests of the packet files. Outside vetters get a
   verifiable audit surface without a single diff or transcript
   shipping in the public repo. boardkit's own board sets
   `posture = sidecar`. S12's public-repo seam folds into this design.
3. **Docking: spec now, library later.** boardkit ships a versioned
   docking-convention doc (resolution order, posture table, common-dir
   fallback semantics). rust-holes adopts it as the second consumer;
   library extraction becomes a card only when the second consumer's
   copy diverges. Wiki docking is aura-family work and routes to the
   aura board per this board's charter.
4. **Deferral supersession: newest-wins plus marker.** For the same
   gate on the same card, only the latest deferral renders as live;
   older rows become history. The parser also recognizes the
   field-invented `superseded <date>` annotation as an explicit
   terminator, so the existing R-wave log lines become valid data.
5. **Canary route: codex fallback plus a defined degraded close.**
   `roles.canary` gains `codex-reviewer` as its fallback (the only
   cross-provider escape this board has), and `board-hygiene` gains a
   degraded-close definition: canary-key generated and stored, deferral
   logged with outage evidence, canary owed at next session start.
6. **S14 convergence rule: scope rule plus soft cap.** Primary test: a
   fix-round finding that does not touch the card's reviewed diff, and
   is not a regression the fix introduced in it, is carded rather than
   fixed in-cycle. Secondary: after two fix rounds, a written ruling
   (continue, card, or escalate) is mandatory. The 2026-08-16 ruling is
   the template.
7. **Review guides: per-card now, wave-level redefined.** S15's ranked
   review guide ships in this wave and its 80/20 focus is
   non-negotiable: the packet must tell the reader where to spend time
   on a large diff. The wave-level artifact is not a consolidated
   re-diff. Gate F's object is divergence from the original plan, the
   high-level final shape of the architecture, and how it was tested. A
   design card decides whether generating that packet is worth
   building; ditching it is an acceptable outcome of that card.
8. **Plan review lane.** This plan is reviewed by the codex lane, not
   the metered Antigravity lane. Ledger appended at the end of this
   document.

## Rollback

Reverts are per card, not per phase: every commit carries its `Card:`
trailer, and the Phase 1 cross-check makes each card's recorded range
checkable against that trailer search, so a card's commits are
identifiable even where a phase spans several cards. Phase 0's board
writes are plain-text card edits, recoverable from git history.
Receipts revert with their card's commits. The sidecar is append-only
external state: a reverted Phase 5 leaves its pushed packets in place
as unreferenced objects, which is harmless, and the receipt revert
removes every tracked pointer to them; no sidecar deletion is part of
any rollback.
